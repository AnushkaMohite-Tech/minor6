#QuickBite – Restaurant Menu and Order Calculator

#1. Project Description:-
QuickBite is a simple restaurant web application developed using Python Flask. It allows users to view food items, select their favourite food, enter the quantity and calculate the total bill.
The application provides a simple and user-friendly interface for placing food orders.

#2. Objectives:-
* To understand the fundamentals of Flask.
* To develop a web application using Python.
* To implement GET and POST methods.
* To accept user input through HTML forms.
* To calculate the total order amount.
* To implement basic input validation.

#3. Technologies Used:-
* Python
* Flask
* HTML
* CSS
* Visual Studio Code

#4. Project Features:-
1. Home Page – Displays the introduction to QuickBite.
2. Menu Page – Displays available food items and their prices.
3. Order Page – Allows users to select food and quantity.
4. Bill Calculation – Calculates the total amount.
5. Input Validation – Handles invalid quantity and food selection.

#7. How to Run the Project:-
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install Flask using:
   pip install -r requirements.txt
5. Run the application:
   python app.py
6. Open the browser and visit:
   http://127.0.0.1:5000/

#8. Conclusion:-
QuickBite demonstrates the basic implementation of a web application using Python Flask. It provides food menu display, order processing, bill calculation and input validation. This project helped in understanding Flask routes, HTTP methods, HTML forms and integration of frontend with backend.
